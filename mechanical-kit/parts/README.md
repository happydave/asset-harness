# Rover part-mesh catalog (v1) — for Sounding `Part` / WI 608

Integration artifacts for the Sounding session to retrieve. Generated by
[`../prototypes/blender_parts.py`](../prototypes/blender_parts.py) (parametric Blender, headless on
`ai2`); regenerate with:

```
scp prototypes/blender_parts.py ai2:/tmp/ && \
ssh ai2 'cd /tmp && blender --background --python blender_parts.py -- --out /tmp/mk_parts --cell-size 0.5'
scp ai2:/tmp/mk_parts/'*' parts/
```

## Contract (read from `crates/sim/src/{voxel,rover}.rs`)

- **Frame:** `+Y` up, `+Z` forward, `+X` lateral (the wheel axle); steering is about `+Y`.
- **Origin:** each mesh's origin is its **mount point** — what `Part.mount` (metres, lattice frame)
  positions. Drop the mesh at `Part.mount` with identity rotation and it sits correctly.
- **Units:** metres. **glTF Y-up.** Sized for `cell_size = 0.5 m`; regenerate with `--cell-size` to
  match the build (dimensions scale linearly).
- See [`manifest.json`](manifest.json) for per-part origin / orientation / material / vert count.

## Parts

`tire`, `rim`, `suspension` (a wheel station = these three, WI 630, sharing the hub-centre mount),
`seat`, `antenna`, `solar_panel`, `bumper`. Preview:
[`../findings/samples-2026-06-24/parts_contact_sheet.png`](../findings/samples-2026-06-24/parts_contact_sheet.png).

## Surfaces

v1 embeds PBR **material factors** (metal / metal_dark / rubber / solar_glass / fabric). AI-textured
surfaces via the `pbr-materials` track (albedo/normal/roughness/AO) are a follow-up — Sounding may
also apply its own material set at import, as it does for the voxel hull skin.
